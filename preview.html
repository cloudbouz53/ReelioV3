Privacy in Reelio

A concise product-facing summary based on the Reelio implementation requirements.

What Reelio processes

Reelio processes video links and content you choose to add so it can create organized knowledge such as a clear title, explanation, summary, key points, categories, tags and indexing terms.

Internal transcript

Speech-to-text output is an internal processing layer used to understand the content. It is not presented as a user-facing transcript feature.

Credentials

Service credentials are sensitive. Saved values must remain encrypted, masked in the interface, and redacted from logs and error reports.

Storage

Structured library data is stored in Neon PostgreSQL and permanent media is stored in Cloudflare R2. Temporary local files should be deleted after they are no longer needed.

User-facing errors

Reelio should present understandable error messages instead of stack traces, shell output, exit codes or raw infrastructure details.

This mockup is product UI copy, not a substitute for a finalized legal privacy policy.

How can we help?

Start with common questions or run a connection check if Reelio cannot process content.

How do I add a video?
Use Share to Reelio from a supported app, or copy the video URL and paste it on Home.
Can each processing output use a different language?
Yes. Explanation, summary, classification and indexing can each have their own language default.
Why can't Reelio process a video?
Open Connections to check database, storage and local media-tool readiness. Reelio should show a clear status and recovery action if a component is unavailable.
Where is the transcript?
Reelio does not expose the transcript as a user feature. It is used internally only to understand the video.
